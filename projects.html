Global health · Machine learning

Predictive dashboard of Haiti HIV patients

Integrated a CatBoost model with MySQL data infrastructure to estimate patient-level risk of treatment interruption within 28 days, supporting targeted follow-up and differentiated care.

  • Validated ensemble and neural network models with 5-fold cross-validation.
  • Reached 0.90 ROC-AUC and 0.61 F2 score for retention outcome prediction.
  • Deployed a Streamlit dashboard and REST API for scalable use by care teams.

Community safety · Geospatial analytics

Community Opportunity Index

Built a multidimensional census-tract index for Prince William County using PCA, correlation analysis, public datasets, and administrative data to guide community safety planning.

  • Consolidated 100+ internal and external datasets in MS SQL Server.
  • Automated Python ETL pipelines for metric creation and dashboard refreshes.
  • Mapped structural safety, service access, health, housing, mobility, and environmental conditions.
92 census tracts mapped for structural opportunity and service access
